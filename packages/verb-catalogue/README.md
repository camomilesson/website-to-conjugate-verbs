# Verb catalogue package

Public API: `@conjugadora/verb-catalogue` (`src/index.ts`). `src/categories.ts` defines 16 stable category IDs, Spanish
labels, English explanations, valid persons, and the Basic (6) / Advanced (10) /
All (16) presets. Imperative categories use tú/usted/nosotros/vosotros/ustedes;
other categories use the six ordinary persons. No imperative yo exists.

## Canonical production data

`../../public/data/catalogue.json` lists the 100 verbs and version. Each
`../../public/data/verbs/<id>.json` contains the canonical answer arrays for one verb.
These files were generated by the assistant during development. They are served
as static assets; no runtime AI or conjugation engine is involved. Load through
`loadCatalogue` / `loadCatalogueVerb`, which validate schema, coverage, identity,
and dataset version before exposing answers. Loading is cancellable and errors
are surfaced to the caller. Practice loads the selected session data. See [catalogue guide](../../docs/CATALOGUE.md) for the full release review.

## Review record — starter-1, 5 November 2026

Seven verbs: hablar, comer, vivir, ser, ir, tener, levantarse. Every verb covers
all 16 categories: 94 category/person cells per verb, 658 cells in total. This
is grammatical form practice; not every verb/construction is equally frequent
or appropriate in every context (for example, progressive ser).

Review performed by the assistant against reference models, not a native-speaker
certification. Regular paradigms were checked by conjugation group; irregular
simple forms, irregular future stem, participles/gerunds, and imperative anchors
were checked separately. Compound categories use the reviewed haber auxiliaries
and invariant participle; present progressive uses estar + gerund.

- hablar/levantarse: regular -ar pattern; nosotros accents in preterite imperfect
  indicative and imperfect subjunctive checked.
- comer: regular -er pattern, including coméis/comió/comiéramos/comiésemos.
- vivir: regular -ir pattern, including vivimos/vivís and vivieron.
- ser/ir: shared irregular preterite and imperfect subjunctive, different
  present/imperfect forms, and sido/siendo versus ido/yendo checked.
- tener: tengo/tienes, tuve, tendr-, tenga, tuviera/tuviese, ten, tenido/teniendo.
- levantarse: pronouns precede finite and perfect forms; affirmative commands
  include levántate/levántese/levantémonos/levantaos/levántense. Negative commands
  keep separate pronouns. Present progressive accepts both pronoun placements
  with the required accent when attached to the gerund.
- Both -ra/-se variants share imperfect subjunctive answer arrays and both haber
  variants share pluperfect subjunctive arrays. Affirmative nosotros ir accepts
  vamos and vayamos.

References consulted for grammatical verification, not imported datasets:

- [RAE student dictionary conjugation appendix](https://www.rae.es/diccionario-estudiante/docs/conjugaciones-verbales.pdf): regular models (printed pp. 1478–1480), ser (1509), tener (1510), ir (1499), auxiliaries. No published table is bundled as an asset.
- [FundéuRAE: reflexive imperatives](https://www.fundeu.es/consulta/imperativo-verbos-reflejos-2482/): vosotros pronoun/consonant handling.
- [UOC: verbs](https://www.uoc.edu/es/servicios/lengua-estilo/criterios/gramatica/verbos): imperative persons and periphrastic/reflexive constructions.

## Validation and maintenance

Run `pnpm validate:catalogue` (also part of `pnpm build`) or `pnpm test`.
Checks cover every file, all category/person cells, nonempty unique answers,
manifest consistency, review anchors, invalid input, HTTP failure, stale versions,
and cancellation. These catch regressions and structural errors; they do not
prove the linguistic correctness of every string.

To change answers, edit the canonical JSON, review the affected forms, update the
review record and dataset version consistently in every file and manifest, and
run checks. Do not regenerate from a required build-time engine. The catalogue is
small enough to inspect directly. The starter review below is retained as provenance; the release report supersedes its counts.
